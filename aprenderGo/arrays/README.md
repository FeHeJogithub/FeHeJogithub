# Go Array Iteration Example

## 📌 Description
This is a simple Go program that demonstrates how to define an **array of strings** and iterate over it using the `range` keyword.

The program prints both the **index** and the **value** of each element in the array.

---

## 🚀 Technologies Used
- Golang

---

## 📄 Code Overview

- An array of fixed size (`[3]string`) is declared
- A `for range` loop is used to iterate over the array
- `fmt.Printf` is used to format the output
