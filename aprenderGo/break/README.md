# Go Control Flow Example

## 📌 Description
This project demonstrates basic **control flow structures in Go**, including:
- `for` loop with `break`
- `if` conditional
- `switch` statement

It is designed as a beginner-friendly example to understand how program execution flow works in Go.

---

## 🚀 Technologies Used
- Golang
- fmt package

---

## 📄 Code Explanation

### 🔁 For Loop with `break`
- Iterates from `0` to `4`
- Stops the loop when `i == 3`
- Prints only `0`, `1`, and `2`

### 🔀 Switch Statement
- Evaluates the value of `x`
- Executes the matching case
- Shows that `break` is optional in Go switch statements
