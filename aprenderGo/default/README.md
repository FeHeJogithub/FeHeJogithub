# Go Switch Statement (Default Case)

## 📌 Description
This project demonstrates a simple **`switch` statement in Go** using a `default` case.

The `default` case executes when none of the defined cases match the value.

---

## 🚀 Technologies Used
- Golang
- fmt package

---

## 📄 Code Explanation

```go
x := 3
switch x {
case 1:
	fmt.Println("one")
default:
	fmt.Println("Not one")
}
