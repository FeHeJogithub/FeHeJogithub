# Go Goroutines Concurrency Example

## 📌 Description
This project demonstrates **concurrency in Golang** using **goroutines**.

It shows how functions can run **concurrently** (in separate lightweight threads) without blocking the main program.

---

## 🚀 Technologies Used
- Golang
- Goroutines
- time package
- fmt package

---
